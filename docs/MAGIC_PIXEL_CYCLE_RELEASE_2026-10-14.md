## Обратная связь во время проверки

Автор сразу отметил непонятный шаг «Источники» при добавлении класса. Причина: набор первого Cycle использовал совместимый общий список заклинаний вместо явной принадлежности классу. В коде исправляются сам набор и обычное создание; для старого одноклассового листа сохраняется однозначная прежняя трактовка доступных заклинаний в черновике повышения. Неизвестные, чужие и смешанные записи требуют понятного выбора, не присваиваются новому классу. Отмена не должна ничего записывать. Следующая сборка с этой правкой не считается установленной автоматически.

Общая готовность магии/импорта остаётся открытой. После всего текущего блока предложен следующий крупный отрезок — инвентарь/экипировка/Кузница с привязанными городскими операциями; это предложение порядка, а не запуск отложенной реализации до приёмки магии и импорта.
