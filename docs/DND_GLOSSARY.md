# Глоссарий QDnD

Это обязательный словарь для новых и изменяемых русских подписей, подсказок,
редакторов и встроенных описаний. Он фиксирует терминологию проекта, согласованную
с автором. При работе с любым разделом проверяем и окружающий текст.

| Понятие | Русский термин | Правило употребления |
| --- | --- | --- |
| Spell level | Круг заклинания | «Заклинание 3-го круга», «ячейка 3-го круга», «Круг 3». Не «уровень заклинания». |
| Character / class level | Уровень персонажа / класса | «Колдун 11-го уровня». Не заменять на «круг». Рост урона заговора зависит от уровня персонажа. |
| Cantrip | Заговор | В интерфейсе — «Заговоры», а не «Круг 0». |
| Spell slot | Ячейка заклинания | Ячейка — расходуемый ресурс; заклинание — известная или подготовленная способность. |
| Hit points / temporary hit points | ОЗ / временные ОЗ | По решению автора компактные подписи интерфейса — HP (EN) и ОЗ (RU); полное название — «Очки здоровья». В текстах правил допустим термин «хиты». |
| Hit die / hit dice | Кость хитов / кости хитов | Отличать кость хитов от текущих ОЗ. |
| Armor class | Класс доспеха, КД | КД — допустимая компактная подпись. |
| Difficulty class | Сложность, Сл | Сл спасброска и КД — разные величины. |
| Saving throw | Спасбросок | Не смешивать с проверкой характеристики или броском атаки. |
| Ability check / proficiency bonus | Проверка характеристики / бонус мастерства | Использовать соответствующий термин, а не общее «бонус». |
| Deafened / stunned | Оглохший / оглушён | Различать потерю слуха и оглушение; это разные состояния. |
| Concentration | Концентрация | Отдельная отметка поддерживаемого заклинания. |
| Short rest / long rest | Короткий отдых / длительный отдых | Встроенные тексты не чередуют «длительный» и «продолжительный». |
| Wizard / sorcerer / warlock | Волшебник / чародей / колдун | Это разные классы; названия не взаимозаменяемы. |
| Evocation | Воплощение | Школа заклинаний, не «эвокация». |
| Class feature / skill / feat | Умение класса / навык / черта | Различать приобретаемое умение, владение навыком и черту; не называть всё «способностями». |
| Ability Score Improvement | Улучшение характеристик | Название шага ASI; выбор черты обозначается отдельно. |
| Proficiency / expertise | Владение / компетентность | Бонус мастерства, владение и компетентность не взаимозаменяемы. |
| Mystic Arcanum | Таинственный арканум | Круг относится к заклинанию: «Таинственный арканум (6-й круг)». |

Термины оформляются через `lib/l10n/*.arb`, включая подсказки выбора заклинаний.
Для кругов используется `levelLabel` / `levelSlot`; `levelShort` предназначен для
уровня персонажа. Новые механики и названия пополняют этот словарь до появления
разных вариантов в интерфейсе. Английские подписи используют английскую
терминологию D&D.

Изменения глоссария не меняют числовые правила, технические идентификаторы,
названия полей JSON/Hive и сохранённые данные. Тексты импортированных библиотек и
собственные записи игрока сохраняются в исходном виде: это содержимое источника,
а не подписи приложения. Встроенные определения исправляются в `assets/data`;
сохранённые копии не переписываются автоматически при открытии листа.

Проверка перед завершением правки: русский экран, соответствующие фильтры и
редактор; поиск старых вариантов в изменяемом разделе; различение уровней
персонажа и кругов заклинаний во встроенных описаниях.

Уточнение автора 10 октября 2026: подписи должны звучать аутентично и спокойно. В игровых формах не использовать внутренние технические термины («пул», «транзакция», «норма ресурса»), рекламные лозунги и избыточную стилизацию под рассказ мастера. Основной текст называет действие и его результат; сведения о сохранении/происхождении доступны по запросу. Пользовательские записи и тексты сторонних книг не переписываются ради этого правила.
