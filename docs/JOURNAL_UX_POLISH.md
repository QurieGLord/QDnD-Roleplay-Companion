# Журнал и лист — исправления взаимодействия

8 октября 2026. Уточнение после проверки рабочего журнала автором на Pixel. Данные журнала и формат переноса не меняются; награды остаются в S07 общего to-do.

## Что изменилось

- В полоске подсказок новые варианты расположены перед знакомыми историями. При появлении нового кандидата полоска возвращается к началу; продолжение ввода того же слова не перезапускает прокрутку. Новые чипы проявляются мягко, появление панели меняет высоту плавно. Режим уменьшенной анимации учитывается.
- В стандартном меню выделения текста заголовка/записи и на странице чтения добавлено «Связать с историей». Можно выбрать существующую историю либо создать новую из выделенной фразы. Выделение захватывается до закрытия меню; исходный текст не переписывается. В узком стандартном меню команда может находиться в дополнительных действиях.
- Поле тегов имеет постоянный ключ и свой FocusNode. Набор тега больше не запускает анализ текста и перестройку подсказок на каждой букве. Панель над клавиатурой активна только при вводе заголовка/текста. Ключи остальных полей сохраняют идентичность при появлении/скрытии соседних блоков. Первый ввод всё равно отмечает черновик изменённым, чтобы закрытие не потеряло тег молча.
- Заголовки записи/задания сохраняют цвет при прокрутке: отключена скачущая тональная подложка AppBar, включая общую тему приложения.
- Тап по вкладке сразу выбирает её и запускает короткое проявление. Лист больше не прокручивает промежуточные страницы за одну короткую анимацию; свайп по PageView сохраняется. Карточка героя отдельно плавно раскрывает/скрывает занимаемое место. Быстрые последовательные тапы проверены.
- В инвентаре оставлен один появляющийся «+» оболочки листа. Через его каталог по-прежнему доступны библиотека и Кузница. Собственная кнопка вкладки скрыта при встраивании, но доступна при самостоятельном использовании InventoryTab.
- Ручка числовых редакторов вынесена из прокручиваемого содержимого в отдельную неподвижную область. Медленное движение вниз и быстрый жест закрывают окно без сохранения. Во время сохранения жест отключён; содержимое по-прежнему можно прокручивать. Ошибка сохранения оставляет редактор открытым.
- Развёрнутые сведения героя используют один SizeTransition вместо вложенных конкурирующих изменений высоты. Шеврон поворачивается; закрытие/раскрытие учитывает режим уменьшенной анимации. Убраны неотменённые удержания прокрутки и автоматическое сворачивание, которое конфликтовало с жестом раскрытия.
- Записи мягко проявляются при входе в видимую область. Геометрия строки и положение списка не анимируются; уже просмотренная запись не повторяет вход при возврате. Состояние журнала сохраняется между вкладками. Прогресс подзадач меняется плавно; заголовки разделов получили компактные акценты в общей палитре.

## Проверки

**336 прошли, 2 прежних пропуска**. Новые сценарии: новая подсказка левее знакомой; ввод через реальный владелец клавиатуры в поле тегов без изменения текста записи; выделенная фраза → подтверждение истории → сохранение без изменения исходной строки; дальний/быстрый тап без промежуточных вкладок; обычный свайп; одна кнопка инвентаря и сохранённый вход в Кузницу; медленный жест ручки без применения черновика; последовательное изменение высоты карточки; отсутствие анимации при reduced motion; однократное проявление записи при прокрутке и возврате. Диагностика изменённого кода фиксируется в evidence/journal-ux-analyze.log.

Тесты проверяют поведение и отсутствие сбоев, но субъективное ощущение плавности окончательно оценивается на устройстве. Продолжительность анимаций ограничена; при дальнейшем наполнении журнала учитываем скорость ввода и читаемость за столом.

## Сборка и приёмка

Собирается отдельный пакет `com.qdnd.qd_and_d.cyclecheck` с обычным листом. Уже введённые записи и истории сохраняются. APK установленной предыдущей рабочей Cycle копируется перед обновлением для возврата без удаления приложения. Основное QDnD не заменяется.

Что проверить на Pixel: новые подсказки слева; выделение фразы и команда связи в меню; длинный тег при открытой клавиатуре; прокрутка страницы записи; прямой тап обзор → журнал; вход в инвентарь и один «+»; медленное движение вниз за ручку редактора ОЗ/КД; раскрытие/скрытие сведений героя. Плавность сравнить также в своём привычном режиме системы/палитре.

Финальный release APK собран: `QDnD-Journal-UX-Cycle-2026-10-08.apk`. Диагностика изменённых файлов — без замечаний.

На эмуляторе проверены прямые переходы, единственная кнопка добавления в инвентаре, медленное движение ручки редактора ОЗ с открытой клавиатурой, новое имя Lyra слева от знакомого Элиана, последовательный нативный ввод `clue wharf` в поле тегов. Существующие записи, включая ранее созданную Nora, остались. Черновик проверки не сохранялся. Снимки и короткое видео находятся в evidence.

На Pixel 9 установлен финальный APK через install -r, получен Success. Перед установкой сохранена точная предыдущая рабочая Cycle как `QDnD-Journal-before-UX-Pixel-2026-10-08.apk`. Основной `com.qdnd.qd_and_d` не обновлялся; его прежняя дата обновления проверена. На телефоне пользователь проверяет живое ощущение анимаций; никакие его записи не редактировались агентом.
