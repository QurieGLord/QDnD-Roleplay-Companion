# Journal Cycle — проверка на устройстве

8 октября 2026. Это отдельный нативный эксперимент для выбора интерфейса журнала; варианты ещё не приняты в продукт.

## Изоляция и возврат

- Пакет: `com.qdnd.qd_and_d.cyclecheck`, название **QDnD Cycle Test**. Основное приложение `com.qdnd.qd_and_d` не заменяется.
- Отдельный запуск `lib/main_journal_cycle.dart` не инициализирует StorageService и не открывает/мигрирует персонажей. Исходный `lib/main.dart` не изменён.
- Вымышленные записи находятся в памяти. Отметки заданий, новые записи и редактирование сбрасываются после полного перезапуска процесса или через меню «Сбросить историю демо».
- Прежний Cycle APK сохранён отдельно как `QDnD-Cycle-rollback-2026-10-06.apk`. Возврат — установка этого APK поверх Cycle без удаления приложения. Подпись и идентификатор должны совпадать; результат проверяется перед передачей сборки.
- Это не проверка переноса реального журнала, сохранения связей или миграции моделей. Эти задачи остаются в S04/S06/S07 общего реестра.

## Что попробовать

1. **Фокус.** Нажать «Все истории», выбрать Элиана. Задания и записи фильтруются вместе, цитата остаётся прежней. Найти письмо через поиск.
2. **Обзор.** Открыть «Обзор связей». Перейти из «Последних слов» к письму, вернуться назад. Сравнить зацепки; совпадение имени не подтверждает личность автоматически. Внизу обзора можно показать эту историю в журнале.
3. **Нить.** Посмотреть записи по сессиям 6 и 2. Группировка следует игровым сессиям, а не времени правки заметки; задания остаются выше записей.
4. Отметить задание, открыть и отредактировать запись, добавить свою. Завершение задания не начисляет награду.
5. В меню справа доступны светлая/тёмная тема, RU/EN, инструкция и сброс. Оценить отклик касаний, плавность переходов, читаемость и удобство возвращения к списку.

Обратная связь: какой способ помогает восстановить историю быстрее, что мешает читать/писать за столом, нужен ли обзор отдельно от выборки. Выбор комбинации не фиксируется автоматически по факту тестирования.

## Воспроизведение сборки

В изолированном Android-проекте назначить applicationId тестового пакета и label QDnD Cycle Test; namespace/MainActivity сохранить исходными. Собирать release с `--target lib/main_journal_cycle.dart`. Не менять package основного Android-проекта и не устанавливать тестовый APK как обновление основного приложения.

Проверки: пять widget-сценариев — общая выборка и поиск; отметка задания в обзоре; прямые ссылки и возврат с сохранённым фокусом; сессии в нити; создание/сброс заметки; RU/EN и крупный текст 1.6. Все пять сценариев прошли; анализ новых файлов — без замечаний. Release APK собран. На эмуляторе проверены установка, запуск, откат на старый APK с запуском прежнего лобби, повторная установка нового APK и переходы по связям/возврат/нить. Удаление приложения и очистка данных не использовались. Идентификатор и подпись обоих APK совпадают. После подключения Pixel 9 новая Cycle Test установлена поверх прежней командой install -r и открыта. Основное приложение сохранило прежнюю дату обновления. Точный прежний APK с телефона дополнительно сохранён; его SHA256 совпадает с сохранённым rollback APK. Удаление приложений и очистка данных не выполнялись.
