# Магия и импорт — установка основного пакета для проверки

12 октября автор попросил установить текущий срез поверх основного приложения на Pixel. Установка выполнена; функциональная приёмка среза продолжается. Открытые задачи из [проверки магии и импорта](MAGIC_IMPORT_CHECKPOINT_2026-10-12.md) сохраняются.

## Установленная сборка

- Пакет `com.qdnd.qd_and_d`, обычный запуск `lib/main.dart`.
- APK `QDnD-Magic-Imports-Main-2026-10-12.apk`, ARM64 для Pixel и x86_64 для проверки на эмуляторе.
- Все три флага демонстрационного заполнения явно отключены. Проверочный entry point с искусственными персонажами не включён в эту сборочную копию.
- Подпись совпадает с точным APK, снятым с Pixel перед обновлением.
- Android versionCode 1 / versionName 1.0.0 сохранены. Упорядочение публичных версий остаётся B03/B04; это установленный для авторской проверки срез.

На эмуляторе проверен штатный запуск основного пакета в пустое лобби без тестовых персонажей. На Pixel установка `install -r` завершилась `Success`; основной процесс запущен, приложение видно на экране, экран ошибки инициализации не обнаружен. Дата первой установки сохранена: `2026-10-06 01:50:03`; дата обновления стала `2026-10-12 14:55:53`. Удаление приложения, очистка данных, сброс героев и библиотек не выполнялись. Игровые действия на личных персонажах не выполнялись.

Основание проверки кода: 615 успешных тестов / 2 прежних пропуска, отдельная проверка корпуса и нативный просмотр предыдущей итерации. Установка не заменяет проверку автором его сохранённых персонажей и всех открытых механик.

## Первый проход автора

1. Открыть существующего паладина и его клятву: русский заголовок, описание и сведения доступной книги. Перезагружать или удалять библиотеку ради первого прохода не требуется.
2. Проверить подготовку и применение заклинания: понятный источник/параметры, выбранный способ и однократный расход подходящих ячеек. Ритуал явно отмечен отдельным способом.
3. Перезапустить приложение и проверить сохранённые значения, библиотеку и отображение героя. Затем расширять проверку на остальные классы и смешанные источники.
